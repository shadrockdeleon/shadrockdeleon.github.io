# Shadrock De Leon — Architecture Portfolio

## Files
- `index.html` — page content
- `styles.css` — layout, colors, typography, responsive styling
- `script.js` — mobile menu and project filters
- `assets/featured-render.jpg` — add your chosen hero render here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your preferred contact email.
2. Add your featured architectural render to the `assets` folder and name it `featured-render.jpg`.
3. Replace the six project placeholder blocks with project images as we prepare each case study.

## Publish on GitHub Pages
Upload the contents of this folder (not the ZIP itself) to the root of your `shadrockdeleon.github.io` repository. Keep the `assets` folder. Commit the changes to the `main` branch. GitHub Pages will publish the update.

The site uses a free Google Fonts stylesheet; if internet access is unavailable, it falls back to system fonts.
