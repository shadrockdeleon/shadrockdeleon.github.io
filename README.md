# Shadrock De Leon — Architecture Portfolio

A responsive, minimalist portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and project sections
- `styles.css` — layout, typography, colors, and responsive styles
- `script.js` — mobile navigation and project filters

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. After publishing, your site will be available at `https://YOUR-USERNAME.github.io`.

GitHub's official guide: https://docs.github.com/en/pages/quickstart

## Customize before publishing
1. Replace each colored project placeholder with your own approved project images/renders.
   - Easiest method: create an `images` folder, upload your images, and replace each `.project-image` placeholder in `index.html` with an `<img>` element.
2. Replace `YOUR-EMAIL@example.com` with your professional email address.
3. Review all project names and descriptions. Only publish work you have permission to share.
4. Update your professional summary and software list as needed.

## Notes
- No paid website builder, hosting subscription, or custom domain is required.
- The free GitHub Pages address uses the `github.io` domain.
- Google Fonts are loaded online; the page will use fallback fonts if unavailable.
